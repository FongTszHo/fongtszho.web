# Yazi 使用简易方式

## 基础操作

| 操作 | 快捷键 |
| :--- | :--- |
| 打开 Yazi | `y` 或 `yazi` |
| 关闭 Yazi | `q` |

## 文件操作

| 操作 | 快捷键 |
| :--- | :--- |
| 创建文件 | `a` |
| 复制文件 | `y` |
| 剪切文件 | `x` |
| 粘贴文件 | `p` |
| 查找文件 | `z` |
