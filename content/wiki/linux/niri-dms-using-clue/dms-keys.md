# 🎹 niri + DMS 自定义快捷键指南

> 💡 **提示**：
> - 配置中的 `Mod` 与 `Super` 等效，默认对应键盘 **Win 键**。
> - 所有快捷键已按你提供的 `binds {}` 区块逐行解析，无默认值假设。
> - 修改保存后，按 `Mod+Shift+R` 或终端执行 `niri msg action reload-config` 热重载。

## ⚠️ 核心键位变更提示 (你的自定义布局)
| 原默认行为              | 你的新绑定                  | 说明                  |
| :----------------- | :--------------------- | :------------------ |
| `Mod+K` 焦点上移       | `focus-workspace-down` | **K 现用于切换下一工作区**    |
| `Mod+U` 工作区下移      | `focus-window-up`      | **U 现用于同列窗口上移**     |
| `Mod+H` 焦点左移       | `focus-window-down`    | **H 现用于同列窗口下移**     |
| `Mod+J` 焦点下移       | `focus-column-left`    | **J 现用于焦点左移列**      |
| `Mod+Shift+H` 列左移  | `move-window-down`     | **Shift+H 现用于窗口下移** |
| `Mod+Shift+J` 窗口下移 | `move-column-left`     | **Shift+J 现用于整列左移** |

### 📌 使用建议
1. **肌肉记忆重塑**：你的 `H/J/K/U` 布局已完全自定义，建议打印此表贴于显示器旁，3~5 天即可形成新反射。
2. **冲突排查**：若 `Mod+K` 或 `Mod+H` 无响应，检查输入法（IBus/Fcitx）是否占用了相同组合键。可在输入法设置中关闭全局快捷键，或临时改用 `Mod+Ctrl+字母` 避开。
3. **滚轮辅助**：niri 原生支持滚轮切换工作区/列，适合快速浏览；精细窗口操作建议保留键盘。
4. **持续迭代**：后续如需绑定 `msim`、`ros2` 或 `yazi` 快捷启动，直接在 `~/.config/niri/config.kdl` 的 `binds {}` 末尾追加：`Mod+新键 { spawn "你的命令"; }`。
