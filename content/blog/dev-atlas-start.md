# Dev Atlas 的第一篇记录

这个站点会作为个人开发笔记、项目实践和能力展示的统一入口。

相比把内容散落在不同工具里，我更希望以后只需要维护 Markdown：学习笔记放进 Wiki，阶段复盘写成 Blog，可以展示的实践整理成 Projects。

## 当前目标

- 保留 Obsidian 写作体验
- 使用 Nuxt Content 自动生成页面
- 用 GitHub Pages 零成本部署
- 逐步把飞书旧记录整理成长期内容

## 内容方向

Dev Atlas 会优先记录硬件、Linux、机器人和 AI 工具链相关内容。它不是一次性完成的网站，而是一个会随着学习路线持续扩展的系统。
